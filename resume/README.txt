Resume folder contents:

  Harshit_Talshania_Resume.pdf      - general full-stack resume, linked from the site nav. Committed to git.
  Harshit_Talshania_Resume.docx     - generated by builder/ (gitignored).

  Harshit_Talshania_Resume_Backend.pdf   - backend / integrations variant (Backend, Platform, API roles).
  Harshit_Talshania_Resume_Backend.docx  - generated by builder/ (gitignored).

  Harshit_Talshania_Cover_Letter_Jibble.pdf/.docx/.txt
                                    - the Jibble Group application letter. .txt is for portal paste boxes.

  Harshit_Talshania_Cover_Letter.*  - older generic letter with [Company] / [Role Title] slots.
                                      Stale: cover-letter.json is now tailored to Jibble.

  builder/  - Node scripts that generate everything from the JSON data files:
                cd resume/builder

                node build.js                        (general resume docx)
                node build-pdf.js                    (general resume pdf)
                node build.js data.backend.json      (backend resume docx)
                node build-pdf.js data.backend.json  (backend resume pdf)
                node build-cover-letter.js           (letter docx + pdf + txt)

  Each JSON file has an "outputBase" field that controls the output file name,
  so a variant never overwrites the resume linked from the site.

  Adding a variant: copy data.backend.json, change "outputBase", edit the copy,
  then run both builders with the new file as the argument.
