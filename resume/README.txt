Resume folder contents:

  Harshit_Talshania_Resume.pdf   - the served/resume file, linked from the site nav. Committed to git.
  Harshit_Talshania_Resume.docx  - generated by builder/ (gitignored).
  Harshit_Talshania_Cover_Letter.pdf   - master cover letter with [Company] / [Role Title] swap slots. Committed to git.
  Harshit_Talshania_Cover_Letter.docx  - generated by builder/ (gitignored).
  Harshit_Talshania_Cover_Letter.txt   - plain-text copy for application portal paste boxes.

  builder/  - Node scripts that generate everything from data:
                cd resume/builder && node build.js              (resume docx)
                cd resume/builder && node build-pdf.js          (resume pdf)
                cd resume/builder && node build-cover-letter.js (letter docx + pdf + txt)

  Cover letter: edit builder/cover-letter.json before each application.
  The swapNotes field lists the three things to change (company, role,
  whyThem paragraph). Contact details come from data.json, so the letter
  always matches the resume. Tailored PDFs should be renamed
  Harshit_Talshania_Cover_Letter_[Company].pdf before sending.
